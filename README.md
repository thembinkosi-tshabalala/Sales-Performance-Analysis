Sales Performance Analysis
Project Overview
This project demonstrates an Excel-based sales performance analysis using a 30-record sales dataset.
The analysis focuses on calculating key sales metrics, analysing product and regional performance, identifying monthly sales trends, and presenting business insights through tables and charts.
Objectives

Calculate total sales and sales quantities
Analyse product performance
Compare regional sales performance
Analyse monthly sales trends
Create key performance indicators (KPIs)
Build clear and professional data visualisations
Demonstrate practical Excel analysis skills
